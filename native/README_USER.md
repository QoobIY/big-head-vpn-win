# Big Head VPN — инструкция для Windows

Big Head VPN — компактный нативный клиент для Windows x64. Java, sing-box и
установка в систему не требуются.

## Установка и запуск

Можно использовать установщик `BigHeadVPN-<версия>-windows-x64-setup.exe`:
он предложит папку установки, создаст ярлык в меню «Пуск» и добавит приложение
в список установленных программ Windows. Ярлык на рабочем столе — по желанию.
Для запуска откройте «Big Head VPN» в меню «Пуск». Автозагрузка включается
кнопкой в приложении.

Для переносимой версии:

1. Распакуйте **всю папку** `BigHeadVPN-Native` на локальный диск, например в
   `C:\Program Files\BigHeadVPN` или `C:\BigHeadVPN`.
2. Не запускайте программу непосредственно из ZIP, `\\wsl.localhost` или
   сетевой папки.
3. Не разделяйте файлы: `BigHeadVPN.exe`, `BigHeadVPNStartup.exe`, `msquic.dll`, `WinDivert.dll` и
   `WinDivert64.sys` должны находиться рядом.
4. Запустите `BigHeadVPN.exe`. Для фильтрации процессов подтвердите запрос
   контроля учётных записей Windows (UAC).

Крестик сворачивает приложение в системный трей. Для полного завершения
выберите пункт выхода в меню значка Big Head VPN в трее. Нажмите правой
кнопкой на значок, чтобы увидеть статус, текущее или выбранное подключение,
протокол, режим фильтрации и адрес локального прокси.

## Добавление подписки

1. Вставьте HTTPS-ссылку подписки в поле ввода.
2. Нажмите «Добавить».
3. Выберите группу и сервер.
4. Нажмите «Подключить».

URL подписки сохраняется. Группу можно обновить одной кнопкой или удалить
вместе со всеми входящими в неё серверами.

В это же поле можно вставить одиночную ссылку `vless://`, `hysteria2://` или
`hy2://`. Такой сервер добавится сразу и будет показан в списке «Все серверы».
Выберите строку и нажмите «Удалить сервер», чтобы удалить только этот профиль.
«Удалить группу» удаляет выбранную подписку целиком. При обновлении подписки
удалённый из неё сервер может появиться снова. В строках показаны бейдж
протокола, тип соединения и название подписки.

Поддерживаются:

- Hysteria2;
- VLESS XHTTP `packet-up` через TLS;
- VLESS TCP/raw через REALITY, включая X25519MLKEM768;
- VLESS TCP/raw через REALITY с `xtls-rprx-vision`;
- VLESS gRPC через REALITY;
- TCP и UDP для Hysteria2, VLESS XHTTP и VLESS gRPC;
- TCP для VLESS TCP/REALITY Vision.

Доступность каждого сервера зависит от поставщика подписки:
перед подключением приложение проводит реальный запрос через VLESS. Если
выбранный XHTTP-профиль не передаёт данные, приложение проверит остальные
XHTTP-серверы той же группы, выберет рабочий и запишет это в журнал.

## Локальный SOCKS5 и HTTP CONNECT

После подключения SOCKS5 и HTTP CONNECT доступны на одном адресе и порту,
указанных в правой части окна. SOCKS5 поддерживает `CONNECT` для TCP и
`UDP ASSOCIATE` для UDP на Hysteria2, VLESS XHTTP и VLESS gRPC. HTTP CONNECT
передаёт только TCP. Проверка с этого компьютера:

```bat
curl --proxy socks5h://127.0.0.1:2081 https://discord.com/api/v10/gateway
curl --proxy http://127.0.0.1:2081 https://discord.com/api/v10/gateway
```

Успешный ответ Discord выглядит примерно так:

```json
{"url":"wss://gateway.discord.gg"}
```

Адрес `127.0.0.1` разрешает подключения только с этого компьютера. Адрес
`0.0.0.0` открывает порт на всех сетевых интерфейсах. У proxy нет пароля — не
открывайте этот порт в интернет и используйте `0.0.0.0` только в доверенной
локальной сети. UDP-relay принимает пакеты только от IP клиента, открывшего
управляющее SOCKS5-соединение, и закрывается вместе с этим соединением.

## Фильтрация приложений

1. Отключите VPN, если он уже работает.
2. Обновите список запущенных приложений.
3. Добавьте нужные EXE в список «Выбранные». Для Discord обычно нужны
   `Discord.exe` и `Update.exe`.
4. Поставьте галочку «Направлять выбранные процессы через VPN» и подключите VPN.
5. Полностью закройте выбранные приложения и запустите их заново.

Галочка по умолчанию выключена, её состояние сохраняется. Список приложений
сохраняется независимо от галочки. При переключении галочки во время работы
VPN автоматически переподключается к тому же серверу.

Если галочка снята или список «Выбранные» пуст, работают только локальные
SOCKS5 и HTTP CONNECT; процессный фильтр не запускается. Фильтр поддерживает IPv4/IPv6, TCP и UDP через
WinDivert. Трафик остальных процессов не перенаправляется. Запросы выбранного
приложения к локальному DNS роутера передаются через туннель публичному DNS,
а ответ возвращается приложению от ожидаемого локального адреса.

## Автозагрузка

Кнопка автозагрузки добавляет ярлык «Big Head VPN» в папку автозагрузки
текущего пользователя. Приложение отображается в разделе «Автозагрузка
приложений» Диспетчера задач и в «Параметры → Приложения → Автозагрузка».
Ярлык через оконный запускатель `BigHeadVPNStartup.exe` без интерфейса
запускает задачу Планировщика с необходимыми для WinDivert правами;
отдельного запуска задачи при входе нет, поэтому отключение записи в Windows
останавливает автозапуск. Приложение запускается в трее, VPN подключается
вручную. Отключить автозагрузку можно той же кнопкой.

Ранее включённая автозагрузка автоматически переводится на новый механизм
при запуске обновлённой версии. После переноса папки программы выключите и
снова включите автозагрузку, чтобы обновить путь к EXE.

## Если что-то не работает

- **VLESS XHTTP: сервер закрыл stream-down без ответа** — выбранный сервер не
  передал ответ. Выбранный профиль останется активным в списке; при
  необходимости выберите другой сервер вручную. Ошибка может воспроизводиться
  и в других VLESS-клиентах, если неисправен сам сервер.
- **TLS/QUIC или сервер недоступен** — проверьте интернет и другой сервер.
- **WinDivert error / нужны права администратора** — запустите EXE от имени
  администратора и убедитесь, что `WinDivert.dll` и `WinDivert64.sys` лежат
  рядом с ним. Не запускайте каталог из OneDrive, WSL или сетевой папки.
- **Приложение не попало в VPN** — добавьте правильное имя EXE, подключите VPN,
  затем полностью перезапустите приложение.
- **Порт занят** — выберите другой локальный порт или закройте программу,
  которая уже использует его.

Ошибки показываются в красном баннере и в журнале главного окна. Журнал можно
скопировать кнопкой «Копировать».

## Данные и обновление

Настройки хранятся в `%LOCALAPPDATA%\BigHeadVPNNative\settings.dat` и защищены
Windows DPAPI для текущего пользователя.

Версия показана в шапке окна, меню трея и свойствах EXE. У установленной
версии она также отображается в списке приложений Windows.

Перед обновлением полностью завершите Big Head VPN через пункт «Выход»
в трее. Для установленной версии запустите новый установщик: он обновит
программу в прежней папке. Для переносимой версии замените всю папку
программы файлами новой сборки. Сохранённые подписки и настройки останутся
на месте. Установить старую версию поверх более новой установщик не позволит.

Удаление установленной версии доступно в «Параметры → Приложения» Windows.
Оно удаляет файлы программы, ярлыки и принадлежащую этой установке
автозагрузку. Пользовательские подписки и настройки сохраняются.
