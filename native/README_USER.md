# Big Head VPN — инструкция для Windows

Big Head VPN — компактный нативный клиент для Windows x64. Java, sing-box и
установка в систему не требуются.

## Установка и запуск

1. Распакуйте **всю папку** `BigHeadVPN-Native` на локальный диск, например в
   `C:\Program Files\BigHeadVPN` или `C:\BigHeadVPN`.
2. Не запускайте программу непосредственно из ZIP, `\\wsl.localhost` или
   сетевой папки.
3. Не разделяйте файлы: `BigHeadVPN.exe`, `msquic.dll`, `WinDivert.dll` и
   `WinDivert64.sys` должны находиться рядом.
4. Запустите `BigHeadVPN.exe`. Для фильтрации процессов подтвердите запрос
   контроля учётных записей Windows (UAC).

Крестик сворачивает приложение в системный трей. Для полного завершения
выберите пункт выхода в меню значка Big Head VPN в трее.

## Добавление подписки

1. Вставьте HTTPS-ссылку подписки в поле «Ссылка подписки».
2. Нажмите «Добавить».
3. Выберите группу и сервер.
4. Нажмите «Подключить».

URL подписки сохраняется. Группу можно обновить одной кнопкой или удалить
вместе со всеми входящими в неё серверами.

Поддерживаются:

- Hysteria2;
- VLESS XHTTP `packet-up` через TLS;
- VLESS TCP/raw через REALITY с `xtls-rprx-vision`;
- VLESS gRPC через REALITY;
- TCP и UDP для Hysteria2, TCP для вариантов VLESS.

Доступность каждого сервера зависит от поставщика подписки:
перед подключением приложение проводит реальный запрос через VLESS. Если
выбранный XHTTP-профиль не передаёт данные, приложение проверит остальные
XHTTP-серверы той же группы, выберет рабочий и запишет это в журнал.

## Локальный SOCKS5 и HTTP CONNECT

После подключения SOCKS5 и HTTP CONNECT доступны на одном адресе и порту,
указанных в правой части окна. Проверка с этого компьютера:

```bat
curl --proxy socks5h://127.0.0.1:2081 https://discord.com/api/v10/gateway
curl --proxy http://127.0.0.1:2081 https://discord.com/api/v10/gateway
```

Успешный ответ Discord выглядит примерно так:

```json
{"url":"wss://gateway.discord.gg"}
```

Адрес `127.0.0.1` разрешает подключения только с этого компьютера. Адрес
`0.0.0.0` открывает порт на всех сетевых интерфейсах. У proxy нет пароля — не
открывайте этот порт в интернет и используйте `0.0.0.0` только в доверенной
локальной сети.

## Фильтрация приложений

1. Отключите VPN, если он уже работает.
2. Обновите список запущенных приложений.
3. Добавьте нужные EXE в список «В VPN». Для Discord обычно нужны
   `Discord.exe` и `Update.exe`.
4. Подключите VPN.
5. Полностью закройте выбранные приложения и запустите их заново.

Если список «В VPN» пуст, локальный SOCKS5 продолжает работать, но процессный
фильтр не запускается. Фильтр поддерживает IPv4/IPv6, TCP и UDP через
WinDivert. Трафик остальных процессов не перенаправляется.

## Автозагрузка

Кнопка автозагрузки создаёт задачу в Планировщике заданий Windows. Она
запускает Big Head VPN при входе в учётную запись с необходимыми правами.
Отключить автозагрузку можно той же кнопкой.

## Если что-то не работает

- **VLESS XHTTP: сервер закрыл stream-down без ответа** — выбранный сервер не
  передал ответ. Приложение автоматически попробует другой XHTTP-CDN профиль
  той же группы. Ошибка может воспроизводиться и в других VLESS-клиентах, если
  неисправен сам сервер.
- **TLS/QUIC или сервер недоступен** — проверьте интернет и другой сервер.
- **WinDivert error / нужны права администратора** — запустите EXE от имени
  администратора и убедитесь, что `WinDivert.dll` и `WinDivert64.sys` лежат
  рядом с ним. Не запускайте каталог из OneDrive, WSL или сетевой папки.
- **Приложение не попало в VPN** — добавьте правильное имя EXE, подключите VPN,
  затем полностью перезапустите приложение.
- **Порт занят** — выберите другой локальный порт или закройте программу,
  которая уже использует его.

Ошибки показываются в красном баннере и в журнале главного окна. Журнал можно
скопировать кнопкой «Копировать».

## Данные и обновление

Настройки хранятся в `%LOCALAPPDATA%\BigHeadVPNNative\settings.dat` и защищены
Windows DPAPI для текущего пользователя.

Для обновления замените файлы программы новой сборкой, предварительно
полностью завершив Big Head VPN через трей. Сохранённые подписки и настройки
останутся на месте.
