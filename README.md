# Big Head VPN for Windows

## Native Preview (C++20)

Новая специализированная Windows x64-версия находится в `native/`. Она не
использует Java и sing-box. Сейчас готовы нативный интерфейс, подписки/группы,
WinHTTP-загрузка, защищённое DPAPI-хранилище и компактное MsQuic-ядро.
QUIC/TLS, HTTP/3/QPACK, авторизация Hysteria2 и TCP CONNECT через локальный
SOCKS5 relay проверены на официальном сервере и реальной подписке. UDP relay и
системный режим ещё разрабатываются, поэтому Preview пока не меняет маршруты Windows.

Сборка из WSL:

```bash
./scripts/build-native-windows-wsl.sh
```

Результат:

```text
dist/BigHeadVPN-Native/BigHeadVPN.exe
dist/BigHeadVPN-Native/msquic.dll
```

LLVM-MinGW используется только при сборке и в приложение не попадает. MsQuic —
официальная QUIC-библиотека Microsoft; её лицензия кладётся рядом с EXE.

## Java-версия

Java 21/Swing-клиент для Windows с интерфейсом в стиле Discord. Сетевое ядро — проверенная версия `sing-box 1.13.14`.

## Возможности

- VLESS: TCP/raw, HTTP/H2, WebSocket, gRPC, HTTPUpgrade, TLS и Reality.
- Hysteria2: `hysteria://`, `hysteria2://` и `hy2://`.
- Полный системный VPN через TUN: весь TCP/UDP-трафик Windows идёт через выбранный сервер.
- Отдельный SOCKS5 + HTTP прокси-сервер без изменения маршрутов Windows.
- HTTPS-подписки: сохранение URL, обновление и удаление группы вместе с серверами.
- Переключение сервера с корректным перезапуском соединения.
- Встроенный журнал, понятные состояния запуска и ошибки без всплывающих окон.

Фильтрация отдельных процессов намеренно удалена: штатный поиск процессов `sing-box` на Windows оказался недостаточно надёжным для Discord.

## Режимы

### VPN для всей системы (TUN)

Приложение создаёт виртуальный адаптер и направляет весь трафик компьютера через VPN. Windows запросит права администратора только для этого режима.

При необходимости одновременно можно включить локальный прокси-сервер.

### Прокси-сервер

TUN и системные маршруты не создаются. Подключите нужное приложение или другое устройство вручную:

- `127.0.0.1` — доступ только с текущего компьютера;
- `0.0.0.0` — доступ со всех сетевых интерфейсов;
- конкретный локальный IP — доступ только через выбранный интерфейс.

Прокси не использует авторизацию. Не публикуйте его в недоверенной сети и не пробрасывайте порт в интернет.

## Сборка из WSL

```bash
chmod +x scripts/build-windows-wsl.sh
./scripts/build-windows-wsl.sh
```

Если `dist/BigHeadVPN` уже существует, скрипт обновит только JAR внутри готового приложения. Полная пересборка EXE, Java runtime и сетевого ядра:

```bash
./scripts/build-windows-wsl.sh --full
```

Результат:

```text
dist/BigHeadVPN/BigHeadVPN.exe
```

## Сборка и запуск на Windows

Нужен JDK 21:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1
```

Portable app-image:

```powershell
.\scripts\package.ps1
```

Скрипт загрузки использует закреплённый `sing-box 1.13.14` и проверяет SHA-256 по официальному файлу контрольных сумм.

## Данные приложения

Настройки и runtime-конфигурация находятся в `%LOCALAPPDATA%\BigHeadVpn`:

- `settings.properties` — настройки и подписки;
- `config.json` — текущая конфигурация `sing-box`, включая параметры доступа к VPN.

Не публикуйте `config.json` и `settings.properties`.

## Диагностика

- «Access is denied» в TUN-режиме — подтвердите запрос UAC.
- Прокси не запускается — проверьте, не занят ли выбранный порт.
- После аварийного завершения закройте оставшийся `sing-box.exe` через Диспетчер задач и запустите клиент снова.
- Для копирования журнала используйте кнопку «Копировать» или `Ctrl+Shift+C`.
